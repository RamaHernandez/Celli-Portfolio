# Camila Celli Portfolio

Proyecto React/Vite listo para subir a GitHub.

## Cómo correrlo localmente

```bash
npm install
npm run dev
```

## Cómo buildearlo

```bash
npm run build
```

## Estructura importante

- `src/App.jsx`: estructura, páginas, datos de proyectos.
- `src/styles.css`: estilos visuales.
- `public/images`: imágenes reales del proyecto ANN WITH AN E.

## Para editar proyectos

En `src/App.jsx`, editar el array:

```js
const projects = [...]
```

Cada proyecto se actualiza automáticamente en:
- Home
- Projects dropdown
- All Projects
- Project detail
- About thumbnails
- Search
- Final home images
